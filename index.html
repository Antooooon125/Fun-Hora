How Fun-Hora uses XALEN

Fun-Hora is the Jyotish chart app. XALEN Ephemeris is the reusable calculation library behind it. Fun-Hora runs XALEN in your browser to calculate planetary positions and speeds, the ascendant, and ayanamsa. Fun-Hora then applies its chart rules to those values.

  • Vargas Fun-Hora divides zodiac signs into smaller sections and uses the exact positions to place planets in divisional charts such as D9 and D60.
  • Jaimini Fun-Hora assigns roles such as Atmakaraka using the selected seven- or eight-karaka convention.
  • Vimshottari The Moon’s birth nakshatra determines the first dasha ruler. The Moon’s progress through that nakshatra determines how much of the first period remains.
  • Thai chart rules Fun-Hora draws the round and square Thai charts and displays Taksa roles and วิษะ markers.

How Fun-Hora calculates Hora Lagna and Ghati Lagna

Fun-Hora uses XALEN to find the last apparent sunrise at the birthplace before birth and calculate the Sun’s sidereal longitude at that sunrise. It uses the chart’s selected ayanamsa, including the Suriyayart offset when selected. A birth before dawn uses the previous sunrise.

  • Hora Lagna (HL) adds 30° for each hour elapsed since sunrise.
  • Ghati Lagna (GL) adds 30° for each 24 minutes elapsed since sunrise.

Both calculations wrap around the 360° zodiac. The chart shows the reference sunrise in UTC. Fun-Hora uses standard apparent sunrise at sea level and leaves these positions unavailable if no sunrise occurred in the previous 1.2 days. Hora Lagna verses · Ghati Lagna verses

What the Thai Suriyayart setting changes

Use the switch beside the ayanamsa menu to compare XALEN Lahiri with Fun-Hora Suriyayart. When a chart is open, the switch recalculates it from the entered birth details.

An ayanamsa is the angle subtracted from a tropical longitude to get a sidereal longitude. Fun-Hora’s Thai Suriyayart setting reduces XALEN’s Lahiri ayanamsa for the birth date by 0.592° (about 35′31″). For example, if Lahiri is 24.000°, Fun-Hora uses 23.408°. Subtracting a smaller angle moves the sidereal positions forward by 0.592° compared with Lahiri. A placement close to a sign, varga, or nakshatra boundary can therefore change.

This fixed offset is Fun-Hora’s convention. Its agreement with a traditional Suriyayart reference has yet to be independently verified.

About Fun-Hora and what’s new

Fun-Hora is a Jyotish chart workbench with Thai round and square charts, 20 vargas, Jaimini, and Vimshottari.

Version 4.2 preserves full-precision positions, resolves birth times using historical zone rules, and saves calculation settings with each chart.

Thai province and district names and approximate centers are adapted from William J. Reynolds’s Thailand Canonical Administrative-Names Reference (CC BY 4.0).

Chart calculations run in your browser. The map picker loads map tiles from OpenStreetMap. The optional Find button sends the location search to OpenStreetMap contributors via Nominatim.
